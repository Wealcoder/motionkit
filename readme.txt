== Description ==

**MotionKit is a visual GSAP animation builder for WordPress.** Design your website with any page builder or theme, connect it to MotionKit, and add professional scroll animations, text animations, parallax, hover effects and page transitions by pointing and clicking on your live page. No JavaScript, no CSS, no coding.

MotionKit works with **every WordPress page builder and theme**: Elementor, Divi, Gutenberg (block editor), Avada, Bricks Builder, WPBakery, SeedProd, Breakdance, Oxygen, Beaver Builder, Astra, Kadence, GeneratePress, Hello Elementor and any classic or block theme. Build the site your way, then animate it with MotionKit.

Under the hood MotionKit is powered by **GSAP (GreenSock Animation Platform)** and the browser-native **Web Animations API (WAAPI)**. You get the full power of GSAP and its plugins (ScrollTrigger, SplitText, Flip, DrawSVG, MorphSVG and more) with a fast, lightweight runtime that uses the browser's own animation engine. MotionKit writes the GSAP code for you.

**Free forever for 1 website & 15 active animations.** No credit card, no trial clock. Upgrade only when you need more.

= How MotionKit works =
 
1. **Design your website** with any page builder or theme.
2. **Install this connector plugin** and create a free MotionKit account.
3. **Connect your website** with one click.
4. **Animate without coding.** Open the visual editor, click an element, pick one of 95+ presets or build a custom GSAP timeline, preview on every device and publish.
 
Your animations are stored on your own WordPress site and rendered by a bundled runtime built on **GSAP (GreenSock Animation Platform)** and the browser-native **Web Animations API (WAAPI)**. You get the full power of GSAP and its plugins with the speed of the browser's own animation engine, and MotionKit writes the code for you.

= Scroll animations and ScrollTrigger =
 
Create scroll-triggered animations that reveal content as visitors scroll – fade in on scroll, slide in on scroll, scale, rotate, stagger – or scrub an animation to scroll progress for Apple-style storytelling pages. Pinned and sticky sections, horizontal scroll, smooth scrolling (ScrollSmoother), sticky headers, video scrubbing, image sequences and scroll-to anchors are all built in. A modern, visual replacement for AOS and Animate.css.
 
= Parallax animations =
 
Add parallax scrolling to backgrounds, images, text layers and whole sections. Multi-layer parallax, mouse-movement parallax and depth effects, all controlled visually.
 
= Text animations and split text =
 
Powered by GSAP SplitText and ScrambleText, MotionKit animates headings by **character, word or line**: text reveal, typewriter, scramble, domino, scatter, ink drop, pendulum, origami fold, rain fall, spotlight and 20 more. Perfect for animated headlines and hero sections.
 
= Image, SVG and physics animations =
 
Image reveal on scroll, cinematic masks, polygon and aperture reveals, 3D moves, flips and zoom tunnels. Draw SVG strokes with DrawSVG, morph shapes with MorphSVG, move elements along a path with MotionPath, and add real-world motion with Physics2D and Inertia.
 
= Hover, click, drag and page load animations =
 
Hover reveals and magnifiers, 3D tilt, custom cursor effects, click triggers, Draggable elements, Flip layout transitions, page load and entrance animations, page transitions, preloaders, counters, marquees and stagger effects.

= AI animation builder for WordPress: MCP server for Claude, ChatGPT and AI assistants =
 
Animate your WordPress website by describing what you want. MotionKit includes an **MCP server** (Model Context Protocol), so AI assistants such as **Claude**, **ChatGPT** and any MCP-compatible AI client can build real GSAP animations on your live pages.
 
* **Animate with plain language** – ask "fade the hero heading up on scroll" or "stagger the service cards", and your AI assistant picks the element, builds the animation and plays it in the MotionKit editor.
* **Whole-page animation in one prompt** – say "add professional scroll animations to this page" and the assistant reads the page's sections, headings and card groups, then animates each one with consistent, calm timing.
* **Edit with words** – "make it slower", "change the easing", "scrub it with the scroll". The assistant changes the animation you already have instead of stacking new ones.
* **Real GSAP, fully editable** – everything the AI builds is a normal MotionKit animation. See it on the timeline, fine-tune any setting by hand and save it to your library.
* **Uses the editor's own rules** – the AI works through the same validated commands as the editor, so it can only make changes you could make yourself, and every change shows in the live preview.
* **Works with your favourite AI** – Claude (claude.ai, Claude Desktop and Claude Code), ChatGPT and other MCP clients connect with one URL and your MotionKit sign-in.
 
**Connect an AI assistant in three steps:**
 
1. In Claude, open **Settings → Connectors → Add custom connector**. In another MCP client, add a remote MCP server.
2. Enter the MotionKit MCP URL **`https://editor.motionkit.io/mcp`** and sign in with your MotionKit account.
3. Open your page in the MotionKit editor, then ask your assistant to animate it.
 
Building animations from an AI assistant is part of the all plans. On the free plan the assistant can list your sites and open the editor for you.

== Installation ==
 
1. In your WordPress dashboard go to **Plugins → Add New**, search for **MotionKit** and click **Install Now**, or upload the plugin ZIP file.
2. Click **Activate**.
3. Open the **MotionKit** menu and click **Connect** to link your site with your MotionKit account (free to create).
4. Click **Launch Editor**, select any element on your page and apply a preset or build your own animation.
 
**Requirements:** WordPress 6.8 or later, PHP 7.4 or later. Works with any theme and page builder.
 
== Frequently Asked Questions ==
 
= What is MotionKit? =
 
MotionKit is a visual GSAP animation builder for WordPress. You design your site with any page builder or theme, connect it to MotionKit, and add scroll animations, text reveals, parallax, hover effects and page transitions by clicking elements on a live preview, without writing code.
 
= Who makes MotionKit? =
 
MotionKit is built by Wealcoder, the team behind Animation Addons for Elementor and other WordPress plugins and themes used on more than 30,000 websites.
 
= Is MotionKit free? =
 
Yes. The plugin is free and the free plan covers 1 website, 2 pages and 15 active animations with no time limit. Paid plans add unlimited pages and animations, premium presets and AI features.
 
= Why use MotionKit instead of Elementor Pro Motion Effects or Divi's built-in animations? =
 
Built-in builder animations give you a fixed menu of entrance effects. MotionKit gives you real GSAP: scroll-scrubbed timelines, pinning, split text, SVG drawing, Flip transitions, physics and a visual timeline for sequencing several elements. It also works identically across every builder, so your animations are not locked to one tool, and you can reuse them on other sites.
 
= Do I need to know GSAP or JavaScript? =
 
No. MotionKit generates the GSAP and Web Animations API code for you. If you do know GSAP, you will recognise ScrollTrigger start/end, scrub, pin, stagger and easing controls.
 
= How do I add GSAP animations to WordPress without coding? =
 
Install MotionKit, connect your site, open the visual editor, click an element and choose a preset such as "Text Reveal" or "Stagger Fade Up". Adjust timing, preview on each device and publish.
 
= Which GSAP plugins does MotionKit support? =
 
ScrollTrigger, ScrollSmoother, ScrollToPlugin, Observer, SplitText, ScrambleText, DrawSVG, MorphSVG, MotionPathPlugin, MotionPathHelper, Flip, Draggable, InertiaPlugin, CustomEase, EasePack, GSDevTools and Physics2D.
 
= Does MotionKit work with Elementor? =
 
Yes, with Elementor Free and Elementor Pro, including Elementor V4. Elementor Pro Motion Effects are not required.
 
= Does MotionKit work with Divi? =
 
Yes. MotionKit is fully compatible with Divi 4 and Divi 5 and animates any Divi module, row or section.
 
= Does MotionKit work with Gutenberg, Avada, Bricks, WPBakery, SeedProd, Astra or my theme? =
 
Yes. MotionKit works with the block editor and block themes, Avada, Bricks Builder, WPBakery, SeedProd, Breakdance, Oxygen, Beaver Builder, Astra, Kadence, GeneratePress and any WordPress theme.
 
= How do I create a scroll-triggered animation (ScrollTrigger) in WordPress? =
 
Select an element, choose the Scroll trigger, then set the start and end positions. Turn on Scrub to tie the animation to scroll progress, or Pin to hold a section in place while content scrolls.
 
= Can I add parallax, horizontal scroll or smooth scrolling? =
 
Yes. Parallax, horizontal scroll and smooth scrolling (ScrollSmoother) are available as presets and as custom timelines.
 
= Can I animate text by letter, word or line? =
 
Yes. Split text presets animate headings by character, word or line with stagger, including typewriter, scramble and masked reveal effects.
 
= Can I reuse animations on another website or page builder? =
 
Yes. Save any animation to your library or export it as a JSON file, then import it into any other website built with any page builder.
 
= Can I use AI to build animations? =
 
Yes, in two ways. The editor has built-in AI that adds animation to a page or element from a prompt. MotionKit also provides an MCP server, so AI assistants such as Claude and ChatGPT can connect and add professional animations across your entire website automatically.
 
= How do I connect Claude or ChatGPT to MotionKit? =
 
Add MotionKit as a remote MCP server in your AI assistant using **`https://editor.motionkit.io/mcp`**, then sign in with your MotionKit account. In Claude this is Settings → Connectors → Add custom connector. Open your page in the MotionKit editor and ask the assistant to animate it, for example "add a smooth scroll reveal to every section".
 
= Will MotionKit slow down my website? =
 
No. The runtime is lightweight, built on GSAP and the native Web Animations API, loads only on pages that contain animations and caches compiled timelines. All scripts and styles are bundled locally.
 
= Are animations responsive? =
 
Yes. Every animation has separate settings for desktop, laptop, tablet landscape, tablet and mobile.
 
= Is MotionKit accessible? =
 
MotionKit respects the visitor's "prefers-reduced-motion" setting, so animations are reduced or skipped for users who request it.
 
= Does MotionKit work outside WordPress? =
 
Yes. The MotionKit editor also supports Webflow, Shopify, Wix, Framer and other platforms, and an SDK is available for AI-built and custom-coded websites. This plugin is the WordPress connector.
 
= Do I need a MotionKit account? =
 
Yes, a free account is required to use the hosted visual editor. Published animations are stored on your WordPress site and keep running even if you disconnect.
 
= What happens to my animations if I deactivate or disconnect? =
 
Your animation data stays on your site. Disconnecting only revokes the editor connection; nothing is deleted unless you remove it from the Tools tab.
 
== External services ==
 
MotionKit bundles all of its JavaScript, CSS, runtime and icons locally. The plugin communicates with the MotionKit service only in the following cases:
 
1. **Account connection (admin only).** When you click Connect, the plugin exchanges a token with `https://editor.motionkit.io/connect/token`, validates it via `/connect/validate` and revokes it via `/connect/revoke` when you disconnect. The site URL and the signed token are sent; the token is stored encrypted on your site.
2. **Launching the editor (admin only).** Clicking Launch Editor opens `https://editor.motionkit.io/` in your browser with your site URL and a short-lived signed token so the editor can load a live preview of your page.
3. **AI assistants (optional).** If you connect an AI assistant, it talks to the MotionKit MCP endpoint at **`https://editor.motionkit.io/mcp`**.
4. **Upgrade link (optional).** The dashboard links to `https://motionkit.io`; no site data is sent.
 
No visitor data is sent to MotionKit and the plugin performs no tracking on your front end.

== Source code ==

The compressed JavaScript and CSS in `assets/build/` is generated from human-readable source that ships with the plugin in the `src/` folder, together with the build configuration (`package.json` and `webpack.config.js`). The same source is public on GitHub: https://github.com/Wealcoder/motionkit

* `src/modules/admin/` and `src/css/` build the admin screens (`admin.js`, `admin-tools.js`, `admin-animations.js` and their stylesheets).
* `src/modules/editor-bridge.js` builds `modules/editor-bridge.js`, which connects a page preview to the MotionKit editor.
* `src/motionkit-waapi/` builds `motionkit-waapi.js`, the front-end animation runtime, and `motionkit-waapi-engine.js`.

= Building from source =

1. Install Node.js 18 or later, which includes npm.
2. Download the source: `git clone https://github.com/Wealcoder/motionkit.git`, then `cd motionkit`.
3. Install the build tools: `npm ci` (or `npm install` when building from the plugin zip, which has no lockfile).
4. Build: `npm run build:wp`

The build runs `@wordpress/scripts` (webpack) with `webpack.config.js` and writes the bundles to `assets/build/`.
